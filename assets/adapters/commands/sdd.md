description: Deprecated strict phased delivery; only to finish active SDD work or when the human asks
usage: <id> [--supervised] [--delegated]
---
SDD is deprecated: open new work with {{command:outcome}} instead, and use this only to finish an active SDD work or when the human explicitly asks for SDD. Existing SDD work completes under its original workflow and assurance policies.
Run `npx ways sdd start $ARGUMENTS`, then work phase by phase: fill `.ways/sdd/<id>/<phase>.md` with Goal, Evidence, Decision and Gate, and certify with `npx ways sdd advance`; never edit a certified phase file. Assess durable semantic impact progressively and use {{command:memory}} for separately reviewed memory commits when needed. The reconcile-memory phase records whether incremental memory or release reconciliation was required; it never demands a no-op artifact. At a supervised human gate stop and ask the human to run `npx ways approve` in their own terminal; you cannot approve and must not touch `approvals/` or `reviews/`. During review give {{role:reviewer}} the digest from `npx ways review digest`; it must appear in the review JSON, and any later edit invalidates the review.
Inline (default): you may implement yourself, and still use {{role:explorer}}, {{role:reviewer}} and {{role:qa}} when useful.
Delegated (`--delegated`): you are the orchestrator and never edit production files during implement, review, or validate. At decompose declare tasks with `npx ways task add <id> --title=... [--depends=a,b]`, offering the human parallel or sequential splits. At implement, for each ready task run `npx ways task prepare <id>` and launch one {{role:implementer}} on its worktree with the packet in `.ways/runtime/task.json`; run independent tasks in parallel and dependent ones in sequence; integrate with `npx ways task integrate <id> --commits=...` in order. Delegate review to {{role:reviewer}} and testing to {{role:qa}}, relay their findings back to implementers, and only advance when the gate passes.
If review or validation fails, retain its evidence and reopen only with `npx ways sdd remediate <implement|decompose|plan|specify> --reason=<text>`; it starts a new attempt without rewriting the prior one. Reopened delegated implementation needs fresh tasks and task worktrees before it can advance again.
