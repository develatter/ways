Write `$ARGUMENTS` as one short fact (a convention, decision, pitfall or how to verify something) with `npx ways remember "<fact>" --path=<glob of the code it is about> --type=convention|decision|pitfall|howto`. Keep it to a few lines, check it against the code first, and commit it with the change that taught it.
