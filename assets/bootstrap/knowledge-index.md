# Repository knowledge

Short, current facts agents need and cannot read from the code: conventions, decisions, pitfalls and how to verify things. One fact per file, a few lines each, with `paths:` naming the code it is about. Write one with `ways remember "<fact>" --path=<glob>`; fix or delete it in the same commit as the code that makes it untrue.
